# Sync PC → Obsidian pronto (sem depender de n8n/Drive)

Criado um instalador one-liner que sincroniza este repo direto pra dentro do
seu vault Obsidian, via `git pull` agendado a cada 5 min.

## Como ativar (rode UMA vez no seu PC)

**Linux / macOS:**
```bash
bash <(curl -fsSL https://raw.githubusercontent.com/fabiokansas-maker/automa-o/claude/download-local-files-5hfmT/scripts/install-pc-sync.sh)
```

**Windows (PowerShell, não precisa admin):**
```powershell
irm https://raw.githubusercontent.com/fabiokansas-maker/automa-o/claude/download-local-files-5hfmT/scripts/install-pc-sync.ps1 | iex
```

O instalador:
1. Pergunta o path do seu vault Obsidian
2. Clona o repo em `<vault>/Claude/automa-o/`
3. Cria uma nota `<vault>/Claude/Sobre.md` explicando a estrutura
4. Configura cron (Linux) / launchd (Mac) / Task Scheduler (Windows) pra dar `git pull` a cada 5 min

A partir daí, **tudo que eu commitar aparece no seu Obsidian em até 5 min** (quando o PC tá online). Quando o PC desliga, na próxima vez que ligar ele sincroniza automaticamente.

## Por que esse caminho em vez do workflow n8n + Drive?

- Funciona **agora**, sem precisar de credenciais Drive OAuth nem URL do seu n8n
- Não depende de Drive Desktop instalado
- Mais simples de auditar (você vê o git log)
- O workflow `08-claude-log-sync.json` ainda existe e serve pra quem prefere a rota Drive

## Limitação

Como é `git pull --hard`, qualquer arquivo que você editar dentro de
`<vault>/Claude/automa-o/` é sobrescrito na próxima sync. Se quiser anotar coisas
suas, faça em `<vault>/Claude/MinhasNotas/` ou em outra pasta do vault, fora do clone.
